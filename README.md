# 🐔 GABMIG's SmartPoultry

SmartPoultry is a comprehensive Point of Sale (POS) and Inventory Management System designed specifically for poultry farms and pet supply businesses. It streamlines daily operations by integrating secure user authentication, an intuitive checkout workflow, and automated stock tracking.

---

## 🚀 Features

* **Secure User Management:** Account creation with built-in security questions for recovery.
* **Dynamic Point of Sale (POS):** Fast product selection, real-time order tracking, and customizable order processing.
* **Flexible Checkout System:** Supports multiple payment types (Cash, GCash), order fulfillment tracking (Upfront or To Deliver), and flexible payment statuses.
* **Robust Inventory Tracking:** Categorized stock management filtering across various animal feeds, medicines, and accessories with quick indicator icons for low/out-of-stock items.
* **Module-Based Navigation:** Easy access sidebar linking Dashboard, POS, Inventory, Records, Supplier, and Organization settings.
